# order-service

## Purpose
Provides the starter microservice for the **Order** domain in the Laundry Delivery System MVP.

## Port
3002

## Database
laundry_orders

## Available Endpoints
- GET /
- GET /health
- GET /api/orders
- GET /api/orders/health
- GET /api-docs

## Swagger URL
http://localhost:3002/api-docs

## How To Run
1. Install dependencies: npm install
2. Start in development mode: npm run dev
3. Start in production mode: npm start
