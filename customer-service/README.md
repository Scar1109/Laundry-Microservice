# customer-service

## Purpose
Provides the starter microservice for the **Customer** domain in the Laundry Delivery System MVP.

## Port
3001

## Database
laundry_customers

## Available Endpoints
- GET /
- GET /health
- GET /api/customers
- GET /api/customers/health
- GET /api-docs

## Swagger URL
http://localhost:3001/api-docs

## How To Run
1. Install dependencies: npm install
2. Start in development mode: npm run dev
3. Start in production mode: npm start
