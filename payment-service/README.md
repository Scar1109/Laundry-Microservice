# payment-service

## Purpose
Provides the starter microservice for the **Payment** domain in the Laundry Delivery System MVP.

## Port
3004

## Database
laundry_payments

## Available Endpoints
- GET /
- GET /health
- GET /api/payments
- GET /api/payments/health
- GET /api-docs

## Swagger URL
http://localhost:3004/api-docs

## How To Run
1. Install dependencies: npm install
2. Start in development mode: npm run dev
3. Start in production mode: npm start
