# laundry-processing-service

## Purpose
Provides the starter microservice for the **Laundry Processing** domain in the Laundry Delivery System MVP.

## Port
3005

## Database
laundry_processing

## Available Endpoints
- GET /
- GET /health
- GET /api/laundry
- GET /api/laundry/health
- GET /api-docs

## Swagger URL
http://localhost:3005/api-docs

## How To Run
1. Install dependencies: npm install
2. Start in development mode: npm run dev
3. Start in production mode: npm start
