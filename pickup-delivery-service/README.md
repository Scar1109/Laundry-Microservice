# pickup-delivery-service

## Purpose
Provides the starter microservice for the **Pickup & Delivery** domain in the Laundry Delivery System MVP.

## Port
3003

## Database
laundry_deliveries

## Available Endpoints
- GET /
- GET /health
- GET /api/deliveries
- GET /api/deliveries/health
- GET /api-docs

## Swagger URL
http://localhost:3003/api-docs

## How To Run
1. Install dependencies: npm install
2. Start in development mode: npm run dev
3. Start in production mode: npm start
